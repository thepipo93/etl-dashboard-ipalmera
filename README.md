# EDA Dashboard — Pipeline ETL iPalmera 2025

Dashboard interactivo que consolida 5 fuentes de datos de publicidad digital en una vista unificada.

## Fuentes de datos
- Google Ads (Search, Display, Performance Max, Demand Gen)
- Meta Ads (Trafico, Alcance, Conversiones, Mensajes)
- Google Analytics 4 (Sesiones, Usuarios, Pageviews)
- Google Search Console (Clicks e Impresiones organicas)
- Ventas / Polizas (datos del cliente)

## KPIs principales
- Inversion total: $52.9K USD (Google $42.7K + Meta $10.3K)
- Ventas: $187K USD (1,011 polizas)
- ROAS: 3.5x

## Stack
- HTML + CSS + Chart.js v4.4.7
- Single file, zero dependencies, opens in any browser
